# 04 正常流程自查

> 适用：02 异常流程、03 页面状态之前，先把「正常情况下这条路是否完整、连贯、可走通」查一遍。
> 边界：本篇只查正常情况是否走得通，**刻意不碰加载失败 / 提交失败 / 条件不满足怎么办**（归 02 异常流程）。

## 检查清单（7 类）

- **01 流程入口**：用户从哪里进入 / 入口是否明确 / 不同入口进入后流程是否一致 / 进入前需满足什么条件 / 是否要前置说明 / 进入后第一步是什么
- **02 流程节点**：有哪些步骤 / 每步用户做什么 / 是否遗漏必要步骤 / 步骤先后关系是否明确 / 能否合并或跳过 / 每步完成后下一步是什么
- **03 页面跳转**：每步完成后跳哪 / 点「下一步」去哪 / 点「返回」去哪 / 点「取消」去哪 / 有无跳转后无法继续的情况 / 流程中页面是否都能连起来
- **04 业务条件**：进入下一步需满足什么条件 / 条件在哪判断 / 条件是否前一步已完成 / 不同条件是否对应不同流程 / 有无需重复判断的条件 / 条件满足后能否进下一步
- **05 用户操作**：当前步用户做什么 / 完成后发生什么 / 是否提示下一步 / 完成后能否继续 / 有无用户不知道下一步做什么 / 用户能否随时知道走到哪一步
- **06 流程结果**：什么算完成 / 完成后页面怎么展示 / 用户看到什么 / 是否要成功提示 / 完成后还能做什么 / 是否引导下一步
- **07 流程完整性**：能否从入口一路走到完成 / 每步是否都有明确下一步 / 有无断开的流程 / 有无重复多余步骤 / 页面操作规则能否对应起来 / 正常情况用户能否顺利完成目标

## 收口 4 问

1. 从哪里开始？
2. 中间经过什么？
3. 每一步做什么？
4. 最后怎么才算完成？
