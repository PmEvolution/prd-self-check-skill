# 02 异常流程自查

> 适用：正常流程基本确定后，沿流程走一遍查异常。
> 核心：正常流程解决「怎么走」，异常流程解决「没按预期走时怎么办」。重点查**高频 + 高风险 + 影响用户继续操作**的场景，不要求每类都写进 PRD。

## 检查清单（14 类异常）

- **01 输入异常**：必填未填 / 格式错误 / 长度超限 / 数量超限 / 特殊字符或非法内容 / 文件格式不支持 / 文件大小超限 / 内容与已有数据重复
- **02 重复操作**：重复点击提交 / 重复支付 / 重复领取 / 重复提交申请 / 成功后再次操作 / 连续快速点击 / 页面刷新后再次操作
- **03 权限异常**：未登录 / 未完成认证 / 角色不符合 / 无操作权限 / 权限发生变化 / 管理员与普通用户权限不同 / 操作对象属于他人
- **04 业务条件不满足**：未满足前置条件 / 超次数限制 / 超数量限制 / 余额不足 / 库存不足 / 不满足地区或年龄条件 / 已达业务上限 / 当前业务阶段不允许操作
- **05 数据异常**：数据为空 / 缺失 / 不存在 / 已删除 / 已失效 / 已过期 / 前后不一致 / 获取到的数据不符合预期
- **06 状态变化**：停留期间状态变了 / 订单被取消 / 申请已失效 / 库存变化 / 数据被他人修改 / 操作对象已不存在 / 当前页状态与实际状态不一致
- **07 并发 / 操作冲突**：多人同时操作同一资源 / 同一资源被同时修改 / 最后一份库存被抢购 / 同用户多端同时操作 / 同数据被多请求修改 / 版本冲突
- **08 中断 / 退出**：中途返回 / 关闭页面 / App 切后台 / 退出登录 / 操作一半重新进入 / 操作到一半页面刷新 / 操作中切换账号
- **09 边界情况**：0 个 / 1 个 / 最小值 / 最大值 / 刚好达最大值 / 超过最大值 / 列表为空 / 列表达最大数量 / 首次使用 / 已使用过
- **10 时间异常**：操作超时 / 倒计时结束 / 活动开始前 / 活动结束后 / 优惠券已过期 / 长时间停留后再操作 / 截止时间前 / 截止时间后 / 跨天跨周期
- **11 接口异常**：请求失败 / 请求超时 / 返回错误 / 返回数据为空 / 返回格式异常 / 服务不可用 / 接口重复请求
- **12 网络异常**：网络断开 / 弱网 / 网络切换 / 请求中断网 / 长时间无响应 / 网络恢复后重操作
- **13 第三方服务异常**：支付失败 / 短信失败 / OCR 识别失败 / 第三方登录失败 / 第三方接口超时 / 第三方不可用 / 第三方返回异常
- **14 设备 / 环境异常**：不同设备 / 不同系统版本 / 不同浏览器 / 屏幕尺寸差异 / App 切后台 / 页面关闭重开 / 浏览器返回 / 相机定位通知等系统权限被关闭

## 异常发生后必答 5 问

① 用户看到什么？（Toast / 弹窗 / 页面状态 / 错误页）
② 用户还能继续吗？（继续 / 重操作 / 须满足条件 / 无法继续）
③ 已填写数据怎么办？（保留 / 清空 / 部分保留 / 下次续填）
④ 能不能重试？（立即 / 等一会 / 只能重来 / 不允许）
⑤ 最终状态是什么？（成功 / 失败 / 待处理 / 取消 / 失效 / 转人工）

> 每类异常扫到时，确认 PRD 里能回答这 5 问，才算覆盖。
