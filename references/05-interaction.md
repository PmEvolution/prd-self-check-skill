# 05 交互自查

> 适用：正常流程、页面状态、业务规则基本确定后，需求评审 / 设计评审前。
> 核心：正常流程走通不代表交互没问题。站在用户角度，把每个关键操作实际走一遍。不要求每项都写进 PRD，先扫描再判断。

## 检查清单（8 维）

- **01 操作方式**：是点击 / 长按 / 滑动还是输入 / 可操作区域是否明确 / 点击区域是否易操作 / 是否容易误触 / 是否符合用户习惯 / 是否需要操作提示
- **02 操作反馈**：点击后是否有即时反馈 / 进行中是否有反馈 / 成功后是否有反馈 / 失败后是否有反馈 / 用户能否判断操作是否完成 / 反馈是否足够明确
- **03 能不能反悔**：能否取消 / 能否撤销 / 删除等重要操作是否需确认 / 返回后之前操作是否保留 / 是否存在「一点就无法恢复」的操作
- **04 防止误操作**：重要操作是否易误触 / 不可操作时是否被误认为可操作 / 是否允许重复点击 / 提交中能否再次提交 / 是否需二次确认 / 默认选项是否易致误
- **05 减少记忆**：是否需记上一页信息 / 关键信息是否需反复查看 / 是否需记编号名称 / 所需信息能否直接看到 / 页面切换后上下文是否保留 / 是否做到「看到就能操作」
- **06 交互一致**：同一种操作方式是否一致 / 同类按钮含义是否一致 / 返回关闭取消是否易混淆 / 同类组件操作是否一致 / 操作反馈是否一致 / 有无不必要的交互差异
- **07 整体体验**：能否一眼看懂怎么操作 / 过程中是否易迷失 / 有无不必要步骤 / 是否易误操作 / 能否及时知道结果 / 用户是否始终知道自己在做什么
- **08 最后检查**：怎么操作？有没有反馈？能不能反悔？容易误操作吗？需要用户记住什么？前后一致吗？
